# 安全与访问控制

[返回 README](../README.md) · [配置参考](configuration.md) · [历史审计](security-audit-2026-10-12.md)

## 权限边界

| 内容 | 默认私有模式的访客 | 公开模式的访客 | 管理员 |
| --- | --- | --- | --- |
| 节点与监控数据 | 需登录 | 可读 | 可读 |
| 节点 IPv4 / IPv6 字段 | 不可见 | 不可见 | 可见 |
| Token、主机配置、通知凭据和管理操作 | 不可访问 | 不可访问 | 可访问 |
| 登录、站点公开信息、安装脚本与 Agent 下载 | 可访问 | 可访问 | 可访问 |

原生和 Komari 兼容遥测遵循同一访问模式。`PROBE_PUBLIC_VIEW=true` 或 `-public` 开放匿名只读看板；管理 REST 接口和 `admin:` RPC 仍要求管理员会话。未经授权的 HTTP 请求返回 `401`，RPC 方法权限错误通过 RPC 错误响应返回。

`/install.sh` 与 `/download/probe-agent` 公开用于目标机器安装，不包含部署 Token；有效 Token 由管理员从受保护的后台获取并传入安装命令。

## 访客 IP 隐私

服务端为访客清空节点 IPv4 / IPv6，覆盖原生 REST、WebSocket、Komari HTTP/WS RPC 和批量调用。内置主题同时隐藏地址区域和复制入口；第三方主题可能保留空白占位。管理员登录后正常可见，原始地址仍用于管理和地区识别。该功能无需 Agent 更新。

退出登录后，现有公开实时连接的后续消息不再携带节点地址；已经发给管理员的数据无法从对方设备撤回。私有模式会关闭失效会话的数据流。按身份区分的数据响应禁止缓存，前端登录状态变化时重新取数。

此规则针对节点地址字段，不扫描名称、标签、备注、探测目标或主题自定义内容中的文本。公开展示前应检查自行填写的内容。

## 账号与会话

- 管理员密码使用 bcrypt（cost 12）哈希。未预设密码时首次启动生成 16 位随机密码，仅在创建时输出到日志，前端要求首次登录后改密。
- 会话摘要以 SHA-256 保存于 SQLite，默认有效期 7 天，重启不会强制登出；改密撤销该账号全部会话。
- 原生和 Komari 兼容 Cookie 均设置 `HttpOnly`、`SameSite=Lax`，HTTPS 下设置 `Secure`；退出时清理两种 Cookie。
- 登录按来源 IP 限流，5 次失败触发 15 分钟锁定；不存在的用户名也执行 bcrypt 比对以减少耗时差异。

账号环境变量仅用于首次创建，恢复办法见[日常运维](operations.md#账号恢复)。

## 代理与来源

浏览器 WebSocket 校验 `Origin`，CORS 只允许同源或 `PROBE_ALLOWED_ORIGINS` 明确声明的来源。默认不信任转发头；仅对 `PROBE_TRUSTED_PROXIES` 中的代理 IP 或 CIDR 接受转发的客户端地址，用于登录限流。

公网部署使用 HTTPS / WSS，并正确配置可信代理与协议转发，详见[部署指南](deployment.md#https-与反向代理)。

## 出站请求

探测目标在保存、Agent 同步和实际连接时默认拒绝回环、私网、链路本地和云元数据等内部地址。TCP / HTTP 探测端口限制为 `53`、`80`、`123`、`443`、`853`、`8080`、`8443`；HTTP 重定向也受检查。

GeoIP、Webhook、主题市场、主题包和镜像改写后的下载 URL 同样检查地址与重定向边界。`PROBE_ALLOW_PRIVATE_TARGETS=1` 会放开相应进程的内部地址及探测端口限制；它不是单个目标的例外。内网探测需在服务端和执行探测的 Agent 上分别设置。

## 主题与请求限额

主题标识 `short` 只接受 1–128 位英文字母、数字、`-`、`_`，保留名 `builtin` 不可用于安装。安装拒绝路径穿越、符号链接、特殊文件和重复成员，在隔离目录验证后替换；校验失败保留旧主题。

| 资源 | 限额 |
| --- | --- |
| ZIP 包 / 单文件 | 各 32 MiB |
| 解压总量 | 128 MiB |
| ZIP 条目 / manifest | 4096 项 / 128 KiB |
| 普通 HTTP 请求体 / 浏览器 WS 消息 | 各 1 MiB |
| 主题上传请求体 | ZIP 限额外加 1 MiB multipart 开销 |
| RPC 批次 / 并发消息 | 32 项 / 8 个 |
| 历史查询窗口 | 720 小时 |

浏览器数据流有心跳和读写期限，私有会话失效后通常在约 5 秒的检查周期内关闭连接。第三方主题仍是浏览器可执行代码，文件系统边界检查不等于对主题脚本的安全审核。

## Agent 与升级边界

Agent 使用有效 Token 连接并主动上报，支持同步探测配置，不提供远程 Shell 或通用命令执行接口。版本号用于展示和比较，服务端不会据此要求 Agent 自我升级；升级由运维人员在目标机器执行安装脚本。

本次依赖与工具链修复需重新构建才会进入二进制。Docker 使用 Go 1.27.2；现有 Agent 与服务端协议兼容，但要获得相应工具链安全更新仍应重建并升级。审计与测试范围见[历史记录](security-audit-2026-10-12.md)，它不替代对实际部署和后续依赖的检查。
